## 👋 Привет! Я Света

QA-инженер, который внимательно проверяет продукт и его детали — от требований до понятного описания найденной ошибки. Сейчас укрепляю базу ручного тестирования и последовательно двигаюсь в сторону автоматизации.

### 🎯 Сейчас в фокусе

- Тест-дизайн, тест-кейсы, чек-листы и качественные баг-репорты
- API-тестирование и SQL
- Python, Java и инструменты автоматизации тестирования
- Git и аккуратная работа с тестовой документацией
